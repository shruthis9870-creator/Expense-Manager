# Expensely — Personal Expense Tracker

> Take control of your money, one expense at a time.

Expensely is a modern, responsive, and intuitive web application designed to track personal finances, manage monthly budgets, and visualize spending habits with interactive charts and real-time analytics.

---

## ✨ Features

- **📊 Comprehensive Dashboard**: Real-time overview of total balance, monthly income, expenses, and savings rate.
- **💸 Transaction Management**: Easily add, edit, filter, search, and categorize income and expenses.
- **🎯 Category Budgeting**: Set monthly budgets by category with visual progress bars and alert notifications.
- **📈 Interactive Analytics**: Breakdown charts powered by Chart.js (expense distribution, monthly trends, and spending flow).
- **🌗 Dark / Light Mode**: Seamless theme switching with persistent preferences.
- **💾 Local Persistence**: All data is automatically saved locally in your browser (`localStorage`).
- **📱 Fully Responsive**: Optimized for desktop, tablet, and mobile screens.

---

## 🚀 Getting Started

No build tools or package managers required. Simply open `index.html` in your favorite web browser:

1. Clone or download this repository.
2. Open `index.html` in Google Chrome, Edge, Firefox, or Safari.
3. Start tracking your expenses!
